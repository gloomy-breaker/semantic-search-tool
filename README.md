# Semantic Search Tool

## What is Semantic Search

Standard search tools like Ctrl + F on Windows and Cmd + F on MacOS are lexical tools, meaning that they rely on matching the user's input character by character to words in a document to find the exact matching word, but what if you dont know what exact word you are looking for, what if you only have an idea for what you're looking for? For example in a document you might be looking for the sentence describing the weather, but the sentence might not explicitly mention the word "weather", meaning that lexical searching tools will struggle to help you locate what you are trying to find while a semantic search tool matches the inputted word to words or sentences from the document through conceptual understanding.

**TLDR:** Semamtic search tools focus on matching by conceptual understanding, meaning and the context rather than literal spelling.
